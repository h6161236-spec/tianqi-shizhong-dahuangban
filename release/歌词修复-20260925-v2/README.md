# CYD 音乐同步 1.0.2

已覆盖安装到连接的手机，原有数据保留。无需重新刷开发板固件。

## 本次修改

- 通知监听服务设为可由系统绑定，仍由系统签名权限 `BIND_NOTIFICATION_LISTENER_SERVICE` 保护。手机之前显示已授权但服务未绑定；更新期间仍遇到系统绑定未恢复，已重新绑定手机原有通知使用权，确认服务连接恢复。
- 收到实时歌词但尚无歌名时，不再显示“未检测到播放器”。先发送“等待歌名”元数据和实时歌词，让现有固件能够打开歌词窗口；通知恢复时补歌名并保留当前歌词。
- 删除基础同步入口、无投送启动分支、麦克风与模拟频谱代码，以及默认整屏授权调用；取消授权不启动同步，系统停止投送时同步服务也停止。
- 使用 Android 14+ 的 App 选择流程，桌面快捷入口复用同一条流程。系统选择器可能仍提供整屏选项，这是 Android 系统界面；应用代码不再请求或默认选定全屏。
