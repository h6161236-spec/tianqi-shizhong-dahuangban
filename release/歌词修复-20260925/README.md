# 歌词位置与长句显示修复（2026-09-25）

本次修复手机端 CYD 音乐同步 App，**无需重刷已有的 2026-09-25 新版固件**。

## 原因与修复

连接用户的 Redmi（25053RT47C）读取媒体会话后确认：小米音乐把当前歌词放在标题字段，歌手字段为 `<unknown>`，真正的歌名在播放器通知中。旧同步 App 将歌词发成 `META` 歌名，并持续清空 `LRC`，造成歌词出现在顶部、歌词区显示“等待歌词”；环形页还会按歌名宽度截断这段文字。

修复后，小米会话缺少歌曲身份时，从同一播放器的通知读取歌名/歌手，从媒体会话持续读取实时歌词。普通播放器仍按正常字段解析；有实时小米会话时不采用可能已冻结的通知歌词。长歌词发送上限从 120 扩大到固件支持的 255 UTF-8 字节，保持完整字符边界。

固件现有环形歌词区宽 148px：新句先停留 1.2 秒，再以 24px/s 循环滚动；短句静止。歌词频谱样式保持两行分页，每 3.6 秒轮换。本次没有修改固件布局。
