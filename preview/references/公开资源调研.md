# 皮卡丘天气钟 · 公开资源与界面参考

核查日期：2026-09-05。目标屏幕：ESP32-2432S028 / ILI9341，320×240。此文档记录公开来源、已看过的参考图及适用范围；`preview/ui.html` 尚未修改。

## 已确认的关键问题

现有页面用 `PK_BODY`、`PK_TAIL`、`PK_LEGS` 手工点阵拼出奔跑角色，而本地 `_pika/pk25.gif` 已经是 PokeAPI 收录的《黑／白》皮卡丘动画。重新取得上游文件后，两者 SHA256 完全一致：

`0DDC94C6F8CD432E3FD8972B4ECA2A7B72FBFAF130C1970726089FEB6FDBACC0`

该 GIF 为 50×46、58 帧。因此角色辨识度问题可以先通过接入现有原始素材解决。它是原地动作循环，不是四脚奔跑动画；接入时应保留原有姿态与比例，不能把它拉长来模拟奔跑。

![皮卡丘原始动画](E:/xiangmu/开发板1/preview/references/assets/pikachu-bw.gif)

## 最值得看的两组界面

### 同款开发板的六页天气界面

![CYD Weather 实机六页](E:/xiangmu/开发板1/preview/references/assets/cyd-weather.jpg)

来源：[CYD-Weather-photo.jpg](https://github.com/HenrysCat/CYD-Weather-Dashboard/blob/main/CYD-Weather-photo.jpg)。它与本项目同为 ESP32-WROOM-32、ILI9341 320×240、XPT2046 触摸和 TFT_eSPI，硬件适配参考价值最高。

可以明确看到：各页面沿用同一条顶部栏、背景、图标语言和底部分页点；内容更换后仍然是一套界面。当前项目的首页是满屏天空场景，其他页却是米白工具页，首先需要解决的就是这层共用结构。

### LVGL 官方音乐演示

![LVGL 音乐界面](E:/xiangmu/开发板1/preview/references/assets/lvgl-music-100.png)

[查看完整动画](E:/xiangmu/开发板1/preview/references/assets/lvgl-music.gif)。来源：[demos/music](https://github.com/lvgl/lvgl/tree/master/demos/music)。已核查 README 明确写明推荐分辨率为 480×272 或 272×480。

这里值得借鉴的是元素之间的主次：播放按钮最明确，歌名与歌手分层，频谱围绕封面组织。移到 320×240 时应减少辅助按钮，为歌词和触摸留空间，不能直接等比缩小整张设计。

## 对三个问题的修改依据

1. **皮卡丘不像**：接入已验证的 PokeAPI 动画，保持比例与原始动作，替换当前手工拼接角色。点击跳跃可作为整只精灵的位置动画保留。
2. **只有首页改，其他页面不搭**：参考 CYD 的共用状态栏／分页体系与 LVGL 的控件规范，在动首页之前先定义五页共同的背景、文本色、字体层级、边距、选中态与弹窗。各来源只借鉴对应部分，最终仍需统一到一套规则。
3. **首页粗糙**：让时间成为第一阅读点，皮卡丘成为主要视觉，天气作为简明摘要。天气场景放在明确区域中；云、雨、地面和文字不要互相遮挡。沿用天气页的同套图标与状态信息。

当前更倾向于“LVGL 的清晰控件与留白 + CYD 的页面结构 + PokeAPI 角色 + Meteocons Flat 天气素材”。这是基于资源核查的取舍建议，尚不是完成的新界面，也没有找到一套可直接替换全部五页的现成皮卡丘主题。
